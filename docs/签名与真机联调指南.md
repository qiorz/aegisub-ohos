# 签名 + 真机联调指南（HarmonyOS 26 / API 26）

## 0. 已准备好的东西

| 文件 | 路径 | 说明 |
|---|---|---|
| 私钥证书库 | `<signing-dir>/app.p12` | ECC P-256，别名 `harmony-app`；密码在 `<signing-dir>/.storepass` |
| 证书请求 | [`app.csr`](app.csr) | **上传到 AGC 用** |
| 签名工具 | `$HARMONYOS_CLT/sdk/default/openharmony/toolchains/lib/hap-sign-tool.jar` | 本地签名 |
| 设备工具 | `hdc`（已在 PATH） | Ver 3.2.0f |
| 连接脚本 | [`hdc-connect.sh`](hdc-connect.sh) | 隧道通了以后一键连接+查设备信息 |

私钥不会离开这台服务器；你只需要把 CSR 换成证书。

---

## 步骤总览

```
你：开手机无线调试 + 建 SSH 反向隧道
我：连上手机，读出 UDID 给你
你：AGC 上传 CSR 换证书 + 用 UDID 注册设备 + 建 Profile，把 .cer/.p7b 给我
我：配置签名、编译、安装、看日志
```

---

## 1. 你：打开手机无线调试 + 建隧道

**手机侧**：
设置 → 关于本机 → 连点「版本号」7 次进开发者模式 →
设置 → 系统和更新 → 开发人员选项 → 打开「**无线调试**」，记下屏幕上显示的 `IP:端口`（端口每次开启会变）。

**电脑侧**（和手机同一 WiFi，且能 ssh 到本服务器）：

```bash
ssh -R 15555:手机IP:5555 root@47.103.26.243
```

保持这个 ssh 会话不要关。看到 `hdc` 那端设备列表里出现手机就说明通了。

> 如果手机无线调试端口不是 5555，把命令里的 `:5555` 换成实际端口。

## 2. 我：连上手机拿 UDID

```bash
./hdc-connect.sh            # 内部执行 hdc tconn 127.0.0.1:15555
```

我会把 `hdc shell bm get --udid` 的结果发你。**这个 UDID 后面要填进 AGC**。

## 3. 你：AGC 三件套

1. **证书**：AppGallery Connect → 证书、APP ID 和 Profile → 证书 → 新增证书
   - 类型选「**调试证书**」
   - 上传 [`app.csr`](app.csr)
   - 下载 `.cer`
2. **APP ID**：确认 bundle name（示例工程是 `com.example.helloharmony`，用你自己的也行，告诉我即可）
3. **设备**：设备管理 → 注册设备 → 填第 2 步拿到的 UDID
4. **Profile**：新增 Profile → 类型「调试」→ 绑定上面的 APP ID + 证书 + 设备 → 下载 `.p7b`

## 4. 你：把 `.cer` 和 `.p7b` 给我

丢到服务器任意目录，或者直接贴文件内容，我来配好：

```json5
"signingConfigs": [{
  "name": "default",
  "type": "HarmonyOS",
  "material": {
    "certpath": "<signing-dir>/app.cer",
    "storePassword": "<p12密码>",
    "keyAlias": "harmony-app",
    "keyPassword": "<p12密码>",
    "profile": "<signing-dir>/app.p7b",
    "signAlg": "SHA256withECDSA",
    "storeFile": "<signing-dir>/app.p12"
  }
}]
```

然后 `hvigorw assembleHap` 直接出 `entry-default-signed.hap`。
若 hvigor 对明文密码不认，退路是构建完用 `hap-sign-tool.jar sign-app` 手动签名，效果相同。

## 5. 我：安装与调试

```bash
hdc install -r entry-default-signed.hap
hdc shell aa start -a EntryAbility -b com.example.helloharmony
hdc shell hilog | grep -i <你的tag>     # 抓日志
hdc file send/receive                   # 传文件
```

## 常见问题

| 现象 | 原因 |
|---|---|
| `device type or API version mismatch` | `compatibleSdkVersion` 高于手机系统 API。26 用 `"26.0.0"`，18 用 `"5.1.0(18)"` |
| 安装报签名校验失败 | Profile 没包含这台设备的 UDID，或证书/Profile 不匹配 |
| `hdc list targets` 为空 | 隧道没建好、手机无线调试关了、或端口不对 |
| 隧道报了但连不上 | 手机与电脑不在同一 WiFi，或电脑防火墙拦了出站 |

## 四、踩过的坑与处理（按出现顺序）

1. **Meson cross file 的 key 是 `pkgconfig`**，不是 `pkg-config`。
   写错时 `found pkg-config: NO`，ICU 直接找不到。
2. **`std::views` 不可用**：OHOS libc++ 15 定义了
   `_LIBCPP_HAS_NO_INCOMPLETE_RANGES`，`<ranges>` 里的 `std::views` 别名被裁掉。
   `provider_convert.cpp` 改用下标反向累加。
3. **Clang 15 不支持 P0960 括号聚合初始化**：`header_colorspace(CM, CR)`
   改为 `header_colorspace{CM, CR}`。
4. **LuaJIT 没有 `lua.hpp`**：Aegisub 的 `lua/ffi.h` 需要 C++ 包装头，构建脚本里生成。
5. **`language_match` 测试反向依赖 GUI**：它 include `src/language_match.h`
   → `<wx/intl.h>`。core-only 下从测试列表移除，其余 371 项不受影响。
6. **musl iconv 编码集太少**：首轮 `lagi_iconv.Roundtrip` 失败。
   强制 Aegisub 自带 GNU libiconv（`-Dforce_fallback_for=iconv`）。
7. **GNU libiconv 的 Meson 构建缺 `LIBDIR`**：`localcharset.c` 引用
   autotools 生成的 `configmake.h`。给子项目加 `-DLIBDIR="/usr/lib"`。
8. **GNU libiconv 下空编码 / `wchar_t` 失败**：
   OHOS 的 `nl_langinfo(CODESET)` 是 `ASCII`，musl 也没定义
   `__STDC_ISO_10646__`。在 `charset_conv.cpp` 做 OHOS 归一化：
   空编码→`UTF-8`，`wchar_t`→`UTF-32LE`。**之后 371/371 全过。**
9. **Boost.Thread 引用 `pthread_setcancelstate`**：OHOS musl 既无声明也无符号，
   给 Boost 打 `__OHOS__` 条件补丁。
10. **ICU out-of-tree 下 host `make install` 报同文件冲突**：
    交叉编译只需要 host 构建树里的 `genrb` 等工具，跳过 host install。
11. **b2 引擎版本不匹配**：用 backports 的 `libboost1.83-tools-dev`（B2 4.10）。
    另外 b2 会追加 `--target=arm64-pc-linux`，包装脚本把 OHOS target 放最后覆盖。
12. **qemu 动态产物仍不可用**：升级 qemu 10 后依旧段错误，静态是唯一通道。

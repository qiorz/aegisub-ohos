# Aegisub 测试 HAP（2026-10-22）

> 所有 HAP 统一放在工作区根目录 `/root/opt/dsh/workspace-aegisub/`，不再放 `out/`。

## 一、这是什么

一个可安装的 HarmonyOS 应用，内置 **Aegisub v3.5.1 libaegisub 完整 gtest 套件（371 项）**。
在应用沙箱里运行，不依赖 shell 可执行权限；跑完可以在界面上**手动导出完整日志**。

产物：

| 文件 | 说明 |
|---|---|
| `AegisubTest-unsigned.hap` | 未签名，43 MB |
| `AegisubTest-selfsigned.hap` | 用本机 OpenHarmony 自签材料签名，`verify-app` 通过；**华为零售设备大概率仍会拒绝** |
| `AegisubTest-signed.hap` | 用你自己的华为调试证书签名后生成（需自备 `.cer` / `.p7b`） |

> 自签 HAP 只能用于接受 OpenHarmony 自签根证书的设备/模拟器。
> 华为设备的信任根是华为，必须用 AGC 签发的调试 profile（bundleName + 设备 UDID 匹配）。
> 这一点在 HandBrake 移植中已实测（`fail to verify pkcs7 file`，9568257）。

## 二、界面与用法

1. 安装并启动 `Aegisub Test`。
2. 点 **运行全部测试**。
   - 首次会把 72 个测试 fixture（2.9 MB）从 rawfile 解到
     `cache/aegisub-tests/`，然后重建 `data/`。
   - 原生模块在后台线程运行 371 项测试，UI 不会卡死。
3. 完成后顶部显示 **总数 / 通过 / 失败 / 耗时**，下方是完整 gtest 日志。
4. **导出日志** → 系统保存对话框，选择任意目录（如下载），日志以
   `aegisub-test-YYYYMMDD-HHMMSS.log` 保存。
5. **复制日志路径** → 把沙箱内路径复制到剪贴板，便于 `hdc file recv`。
6. 若测试崩溃导致应用退出：重新打开应用，会自动载入
   `latest.log` 的残留内容（状态显示“已载入上次日志（可能未跑完）”）。

沙箱内路径：

```text
/data/storage/el2/base/haps/entry/cache/aegisub-tests/
  ├── data/                 # 每次运行重建的测试数据
  ├── tests/                # 从 rawfile 解出的 fixtures
  ├── automation/include/   # lua_lfs 测试需要
  ├── latest.log            # 完整测试输出
  └── latest.json           # 上次成功的结构化结果
```

导出文件不需要任何权限；`DocumentViewPicker` 的 URI 授权由系统处理。

## 三、构建

```bash
cd /root/opt/dsh/workspace-aegisub
bash scripts/build-test-hap.sh
```

脚本会：

1. `scripts/prepare-hap-testdata.sh`：把 `src/Aegisub/tests/{keyframe,vfr,charset,options,lua}`
   和 `src/Aegisub/automation/include` 复制到
   `app/entry/src/main/resources/rawfile/testdata/`，并生成 `manifest.json`；
2. `hvigorw assembleHap`（CMake 交叉编 `libaegisubtest.so`，约 39 MB）；
3. 把 unsigned HAP 复制到工作区根目录；
4. 若设置了签名环境变量，则自动签名。

### 用华为调试证书签名

先在 AGC 创建：

- 调试证书（上传 `/opt/harmony-signing/app.csr` 或你自己的 CSR）
- bundle name 为 `com.example.aegisubtest` 的 APP ID
- 注册设备 UDID（`hdc shell bm get --udid`）
- 调试 Profile（绑定上述证书 + 设备）

然后：

```bash
AEGISUB_SIGN_P12=/path/app.p12 \
AEGISUB_SIGN_CER=/path/app.cer \
AEGISUB_SIGN_PROFILE=/path/app.p7b \
AEGISUB_KEY_ALIAS=harmony-app \
AEGISUB_KEY_PWD='<p12密码>' \
bash scripts/build-test-hap.sh
```

产物 `AegisubTest-signed.hap`。

也可以单独签已有 unsigned 包：

```bash
bash scripts/sign-test-hap.sh \
  AegisubTest-unsigned.hap \
  /path/app.p12 /path/app.cer /path/app.p7b \
  harmony-app '<密码>' AegisubTest-signed.hap
```

### 本次自签包是怎么来的

`hello-harmony/signing/` 里有一组 OpenHarmony 自签材料。为了让 profile 的
bundle-name 与本应用一致，做了两步：

1. 复制 `profile.json`，把 `bundle-info.bundle-name` 改为
   `com.example.aegisubtest`；
2. `development-certificate` 必须是 **URL-safe Base64**（`-`/`_`，无 `=`），
   否则 `hap-sign-tool` 会报 `Illegal base64 character 2f`；
3. `hap-sign-tool sign-profile` 用 `profile.p12 / profile.cer` 重签；
4. `hap-sign-tool sign-app` 用 `app.p12 / app.cer` 签 HAP。

> 这组证书的根是 OpenHarmony Root CA，不是华为根；华为设备会拒绝。

## 六、已知限制

1. **一个进程只能跑一次**。gtest / dispatch / locale 初始化是一次性的；
   再点“运行全部测试”会返回“restart the app”。重启应用即可。
2. 若某个测试直接 abort，应用进程可能退出；`latest.log` 已无缓冲写入，
   重启后可看到残留日志。UI 不会崩溃后自动恢复结果。
3. HAP 43 MB：ICU 静态数据 30 MB + 测试代码；没有做按需裁剪。
4. 首次运行解压 72 个 fixture 约 2.9 MB，通常 <1 秒。
5. 自签包在华为设备上会被拒绝，必须换成华为调试证书/profile。

# Aegisub OHOS 应用（编辑器 MVP + 日志导出，2026-10-22）

> 所有 HAP 统一放在工作区根目录 `/root/opt/dsh/workspace-aegisub/`，不再放 `out/`。

## 一、这是什么

一个可安装的 HarmonyOS 应用，包含两个页面：

- **字幕编辑（MVP）**：打开/新建 `.ass`/`.ssa`，也可导入 `.srt`（转成 ASS 模型），
  用 libaegisub 的 `agi::Time` 解析时间，编辑每行的起止时间、样式和文本；
  另有样式面板可改字体、字号、主色、描边色；保存/导出 ASS，或导出 SRT。
- **视频预览（MVP）**：选择 MP4/MKV/TS，`Video` 组件播放；播放时叠加当前
  Dialogue 文本；暂停后点 **样式渲染**，libass 会按 ASS 样式渲染一帧
  （白字/黑边/字号/颜色），以 PixelMap 叠加到画面上。
- **测试**：在应用沙箱内跑 **Aegisub v3.5.1 libaegisub 完整 gtest 套件（371 项）**，
  跑完可**手动导出完整日志**。

不依赖 shell 可执行权限；所有文件读写都在应用沙箱或用户选择的系统 URI 内。

产物：

| 文件 | 说明 |
|---|---|
| `Aegisub-unsigned-v0.1.2.hap` | **唯一交付物**，版本 `0.1.2`，未签名，51 MB；签名由使用者自行完成 |

> 本工作区之后只产出 unsigned HAP。华为设备的信任根是华为，签名必须使用
> AGC 签发、bundleName 为 `com.example.aegisubtest`、且包含设备 UDID 的调试
> profile（`.cer` / `.p7b`）；OpenHarmony 自签根会被拒绝（`fail to verify pkcs7 file`，9568257）。

## 二、界面与用法

### 字幕编辑（MVP）

1. 启动后默认进入 `Aegisub OHOS` 编辑页；点 **新建** 得到 v4.00+ 空白字幕。
2. **打开** → 系统文件选择器选 `.ass`/`.ssa`/`.srt`，文件会复制到应用沙箱再解析；
   SRT 会转成 v4.00+ ASS 模型，文件名改为 `.ass`。
3. 文件按钮下方有 **导入视频 / 导入音频**，直接选择媒体；也可点模式行的
   **视频 / 音频** 进入对应面板再选择。列表上方可 **搜索台词 / 角色 / 样式**；
   点 **清空** 恢复全部。
   点列表中的行，在下方修改 **开始 / 结束 / 样式 / 文本**，点 **应用**；
   样式可直接从下拉选择（也可手输）。
   **Dialogue/Comment** 按钮切换事件类型；**更多字段** 可编辑 Layer、Actor、
   MarginL/R/V、Effect。时间工具：**-100ms / +100ms**、**起点=当前 / 终点=当前**、
   **复制行**、**排序**（按开始时间）；**全部±100ms** 整体对轴。
4. **保存** 写回沙箱，并把上一版复制为 `.bak`；切后台/离开编辑器时若有未保存
   修改会自动保存。**ASS** 调系统保存对话框导出 ASS；**SRT** 导出
   `HH:MM:SS,mmm` 的 SRT（只导 Dialogue 行，`\N` 还原成换行）。
5. 右上角 **撤销 / 重做**；文件名后的 `*` 表示有未保存修改。
6. 点 **样式** 切换样式面板：**新增样式 / 删除样式**、改名、字体/字号/主色/描边色/
   描边宽/粗体/斜体/对齐；点 **系统字体** 枚举 `/system/fonts` 并下拉选择；
   点 **应用样式**。再点 **台词** 回到行编辑。
7. 点模式行的 **音频** → **选择音频**（MP3/M4A/AAC/WAV/FLAC/OGG），
   播放 / -1s / +1s 定位；**设为起点 / 设为终点 / 选中当前行** 用当前播放位置打轴。
   WAV 会解析 PCM 峰值并显示柱状波形；MP3/AAC 等压缩格式只播放不打波形。
8. 点模式行的 **视频** → **选择视频**，播放时底部叠加当前字幕；
   **跳到选中行** 把播放位置移到选中行起点；**选中当前播放行** 回到台词页
   选中正在播放的行；**样式渲染** 渲染当前帧；**自动样式预览** 打开后按
   400ms 节流自动调用 libass。
9. 点模式行 **日志** 导出应用日志；不再有测试页。

当前 MVP 编辑 `[Events]` 与样式段的关键字段；`[Script Info]`、样式段其余字段、
`[Fonts]` 等原样保留。

### 日志

1. 点模式行 **日志**。
2. 系统保存对话框导出 `aegisub-YYYYMMDD-HHMMSS.log`。
3. 日志包含：版本、当前文件名/沙箱路径、dirty、事件/样式数、status，
   以及新建/打开/保存/导出/音视频/样式渲染的关键操作与错误。
4. **测试页已移除**（v0.1.2 起）；原生 371 项 gtest 仍在 qemu 回归脚本中运行。

导出文件不需要任何权限；`DocumentViewPicker` 的 URI 授权由系统处理。

## 三、构建

```bash
cd /root/opt/dsh/workspace-aegisub
bash scripts/build-hap.sh
```

脚本会：

1. `scripts/prepare-hap-testdata.sh`：把 `src/Aegisub/tests/{keyframe,vfr,charset,options,lua}`
   和 `src/Aegisub/automation/include` 复制到
   `app/entry/src/main/resources/rawfile/testdata/`，并生成 `manifest.json`；
2. `hvigorw assembleHap`（CMake 交叉编 `libaegisubtest.so`，约 39 MB）；
3. 把 unsigned HAP 复制到工作区根目录。

脚本**不会**签名；签名请单独执行下一节命令。

### 用华为调试证书签名

先在 AGC 创建：

- 调试证书（上传 `/opt/harmony-signing/app.csr` 或你自己的 CSR）
- bundle name 为 `com.example.aegisubtest` 的 APP ID
- 注册设备 UDID（`hdc shell bm get --udid`）
- 调试 Profile（绑定上述证书 + 设备）

然后直接签已有的 unsigned 包：

```bash
bash scripts/sign-test-hap.sh \
  Aegisub-unsigned-v0.1.2.hap \
  /path/app.p12 /path/app.cer /path/app.p7b \
  harmony-app '<密码>' Aegisub-signed.hap
```

## 四、安装与启动

```bash
hdc list targets
hdc install -r Aegisub-signed.hap
hdc shell aa start -a EntryAbility -b com.example.aegisubtest
```

抓 hilog：

```bash
hdc shell hilog | grep -i AegisubTest
```

## 六、已知限制

1. **编辑器是 MVP**：编辑 `[Events]` 与样式段的关键字段（字体/字号/主色/描边），
   支持 50 步撤销/重做与未保存标记。视频页可手动渲染单帧，也可打开
   **自动样式预览**（约 2.5 fps，640x360）；不是满帧率字幕。libass 已接
   fontconfig，扫描 `/system/fonts`，样式页可枚举系统字体并下拉选择；
   若系统字体不可用则回退内置 DejaVuSans。
   音频打轴已接 AVPlayer（播放/seek/设为起止）；WAV 有 PCM 波形，
   内置 DroidSansFallback 负责中文 glyph 回退（系统字体缺失时也不会方框）；
   MP3/AAC 等压缩格式没有波形；
   完整样式表、卡拉 OK、自动化脚本仍未实现。
   时间字段会经 `agi::Time` 归一化，TextArea 里的真实换行会转成 ASS 的 `\N`。
2. **测试页一个进程只能跑一次**。gtest / dispatch / locale 初始化是一次性的；
   再点“运行全部测试”会返回“restart the app”。重启应用即可。
3. 若某个测试直接 abort，应用进程可能退出；`latest.log` 已无缓冲写入，
   重启后可看到残留日志。UI 不会崩溃后自动恢复结果。
4. HAP 51 MB：ICU 静态数据 + 测试代码 + libass/harfbuzz/fontconfig；没有做按需裁剪。
5. 首次运行解压 72 个 fixture 约 2.9 MB，通常 <1 秒。
6. 自行签名时必须用华为 AGC 调试证书/profile；OpenHarmony 自签包会被华为设备拒绝。

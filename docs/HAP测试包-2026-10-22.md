# Aegisub OHOS 应用（编辑器 MVP + 测试页，2026-10-22）

> 所有 HAP 统一放在工作区根目录 `/root/opt/dsh/workspace-aegisub/`，不再放 `out/`。

## 一、这是什么

一个可安装的 HarmonyOS 应用，包含两个页面：

- **字幕编辑（MVP）**：打开/新建 `.ass`/`.ssa`，用 libaegisub 的 `agi::Time`
  解析时间，编辑每行的起止时间、样式和文本，保存/导出。
- **测试**：在应用沙箱内跑 **Aegisub v3.5.1 libaegisub 完整 gtest 套件（371 项）**，
  跑完可**手动导出完整日志**。

不依赖 shell 可执行权限；所有文件读写都在应用沙箱或用户选择的系统 URI 内。

产物：

| 文件 | 说明 |
|---|---|
| `Aegisub-unsigned.hap` | **唯一交付物**，未签名，43 MB；签名由使用者自行完成 |

> 本工作区之后只产出 unsigned HAP。华为设备的信任根是华为，签名必须使用
> AGC 签发、bundleName 为 `com.example.aegisubtest`、且包含设备 UDID 的调试
> profile（`.cer` / `.p7b`）；OpenHarmony 自签根会被拒绝（`fail to verify pkcs7 file`，9568257）。

## 二、界面与用法

### 字幕编辑（MVP）

1. 启动后默认进入 `Aegisub OHOS` 编辑页；点 **新建** 得到 v4.00+ 空白字幕。
2. **打开** → 系统文件选择器选 `.ass`/`.ssa`，文件会复制到应用沙箱再解析。
3. 点列表中的行，在下方修改 **开始 / 结束 / 样式 / 文本**，点 **应用**。
4. **保存** 写回沙箱；**导出** 调系统保存对话框，把 `.ass` 存到用户选择的位置。
5. 点右上角 **测试** 进入测试页；测试页右上角 **返回编辑器** 回来。

当前 MVP 只编辑 `[Events]` 表；`[Script Info]`、样式段、`[Fonts]` 等原样保留。

### 测试与日志

1. 在编辑页点 **测试**。
2. 点 **运行全部测试**。
   - 首次会把 72 个测试 fixture（2.9 MB）从 rawfile 解到
     `cache/aegisub-tests/`，然后重建 `data/`。
   - 原生模块在后台线程运行 371 项测试，UI 不会卡死。
3. 完成后顶部显示 **总数 / 通过 / 失败 / 耗时**，下方是完整 gtest 日志。
   测试页仍支持 **导出日志 / 复制日志路径 / 清空显示**。
4. **导出日志** → 系统保存对话框，选择任意目录（如下载），日志以
   `aegisub-test-YYYYMMDD-HHMMSS.log` 保存。
5. **复制日志路径** → 把沙箱内路径复制到剪贴板，便于 `hdc file recv`。
6. 若测试崩溃导致应用退出：重新打开应用，会自动载入
   `latest.log` 的残留内容（状态显示“已载入上次日志（可能未跑完）”）。

沙箱内路径：

```text
/data/storage/el2/base/haps/entry/cache/aegisub-tests/
  ├── data/                 # 每次运行重建的测试数据
  ├── tests/                # 从 rawfile 解出的 fixtures
  ├── automation/include/   # lua_lfs 测试需要
  ├── latest.log            # 完整测试输出
  └── latest.json           # 上次成功的结构化结果
```

导出文件不需要任何权限；`DocumentViewPicker` 的 URI 授权由系统处理。

## 三、构建

```bash
cd /root/opt/dsh/workspace-aegisub
bash scripts/build-hap.sh
```

脚本会：

1. `scripts/prepare-hap-testdata.sh`：把 `src/Aegisub/tests/{keyframe,vfr,charset,options,lua}`
   和 `src/Aegisub/automation/include` 复制到
   `app/entry/src/main/resources/rawfile/testdata/`，并生成 `manifest.json`；
2. `hvigorw assembleHap`（CMake 交叉编 `libaegisubtest.so`，约 39 MB）；
3. 把 unsigned HAP 复制到工作区根目录。

脚本**不会**签名；签名请单独执行下一节命令。

### 用华为调试证书签名

先在 AGC 创建：

- 调试证书（上传 `/opt/harmony-signing/app.csr` 或你自己的 CSR）
- bundle name 为 `com.example.aegisubtest` 的 APP ID
- 注册设备 UDID（`hdc shell bm get --udid`）
- 调试 Profile（绑定上述证书 + 设备）

然后直接签已有的 unsigned 包：

```bash
bash scripts/sign-test-hap.sh \
  Aegisub-unsigned.hap \
  /path/app.p12 /path/app.cer /path/app.p7b \
  harmony-app '<密码>' Aegisub-signed.hap
```

## 四、安装与启动

```bash
hdc list targets
hdc install -r Aegisub-signed.hap
hdc shell aa start -a EntryAbility -b com.example.aegisubtest
```

抓 hilog：

```bash
hdc shell hilog | grep -i AegisubTest
```

## 六、已知限制

1. **编辑器是 MVP**：只编辑 `[Events]`，尚不支持样式编辑、视频/音频预览、
   撤销/重做、卡拉 OK、自动化脚本；时间字段目前按文本保存，尚未做严格校验。
2. **测试页一个进程只能跑一次**。gtest / dispatch / locale 初始化是一次性的；
   再点“运行全部测试”会返回“restart the app”。重启应用即可。
3. 若某个测试直接 abort，应用进程可能退出；`latest.log` 已无缓冲写入，
   重启后可看到残留日志。UI 不会崩溃后自动恢复结果。
4. HAP 43 MB：ICU 静态数据 30 MB + 测试代码；没有做按需裁剪。
5. 首次运行解压 72 个 fixture 约 2.9 MB，通常 <1 秒。
6. 自行签名时必须用华为 AGC 调试证书/profile；OpenHarmony 自签包会被华为设备拒绝。
